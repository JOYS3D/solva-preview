# D&N Concrete & Landscape Solutions — SOLVA concept

Independent, speculative website concept prepared by SOLVA for D&N Concrete & Landscape Solutions in Brisbane. This is not the official D&N website and does not imply a client relationship.

## Preview

This folder is a portable copy of the existing SOLVA concept. It uses relative asset paths and works beneath a GitHub Pages subdirectory, with no build step or dependencies.

## Contents

- Responsive HTML, CSS and JavaScript
- Project image gallery, accessible modal and mobile navigation
- Instagram enquiry links to the business profile supplied for the original concept
- No contact database, analytics, checkout or payment collection
