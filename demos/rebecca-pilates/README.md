# Rebecca — Pilates & Health Coaching

Personalised website concept created by SOLVA for Rebecca’s Pilates and Health Coaching brief.

**Live website:** https://rebecca-pilates-concept.coolenyaya.chatgpt.site

## Included
- Complete responsive static website: HTML, CSS and JavaScript.
- Original illustrative photographs and local fonts with their SIL licenses.
- Service sections, mobile navigation, FAQs and an interactive enquiry preview.
- Relative asset paths so the folder works at a domain root or beneath a subdirectory.

## Run locally
Open a terminal in this folder and run:

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000. No install or build step is required.

## Before a real business launch
This is a speculative design preview, not an official website or verified client reference. Branding, wording, imagery and service descriptions are proposals for Rebecca to approve. Photos show fictional models and settings, not Rebecca or her premises. No qualifications, prices, location or testimonials have been invented.

The enquiry form validates and displays data in the browser only. Nothing is sent or persisted. Connect the approved enquiry destination, confirm business details and booking arrangements before accepting real enquiries. Search indexing is discouraged by the page’s robots metadata.

## Files
- index.html — page content
- style.css — design, responsive layouts, reduced motion
- script.js — navigation and local enquiry preview
- assets/ — photographs, fonts and font licenses
- asset-prompts.json — image-generation provenance

The original site remains hosted through Sites. This folder is its portable GitHub copy; no original hosting credentials or owner configuration are included.
